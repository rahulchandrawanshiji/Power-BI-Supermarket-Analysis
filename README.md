# Supermarket Sales Analysis | Power BI

## Project Overview
This project focuses on analyzing supermarket sales data using Microsoft Power BI. The objective is to transform raw transaction data into meaningful business insights through interactive dashboards and data visualization.

## Project Objectives
- Analyze supermarket sales performance.
- Understand sales and return patterns.
- Explore customer and product performance.
- Track business performance using interactive reports.
- Identify useful trends through data analysis.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Microsoft Excel / CSV
- Git & GitHub

## Dataset Description
The project uses supermarket datasets containing:

- Transaction Data (1997 and 1998)
- Customer Information
- Product Information
- Calendar Data
- Store Information
- Region Information
- Return Data

## Project Activities

### 1. Data Preparation
- Imported multiple CSV files.
- Cleaned and transformed datasets using Power Query.
- Combined transaction files from 1997 and 1998.
- Prepared data for analysis.

### 2. Data Modeling
- Created relationships between relevant tables.
- Worked with Calendar, Customer, Product, Sales and Return tables.

### 3. DAX Calculations
- Created calculated columns.
- Created measures for Quantity Sold and Quantity Returned.
- Calculated revenue and other business metrics.
- Created date-based calculations such as weekends and month-end dates.

### 4. Dashboard Development
- Developed interactive Power BI reports.
- Used charts, tables, filters and visualizations to analyze business performance.

## Project Files

- `SuperMarket_Report.pbix` – Power BI report file.
- `SuperMarket Transactions/` – Transaction datasets.
- `SuperMarket_CSV_Files/` – Supporting datasets.
  
## Key Learning Outcomes
- Practical experience with Power Query.
- Data modeling and table relationships.
- DAX calculated columns and measures.
- Combining multiple CSV files.
- Building interactive Power BI reports.
